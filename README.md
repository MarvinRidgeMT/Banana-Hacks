# ChronoVisage
Provenance-first restoration for historical photos.

**Model licenses.** ChronoVisage is a free, non-commercial tool. Face restoration uses CodeFormer (S-Lab License 1.0, non-commercial use only); a commercial deployment should swap in GFPGAN (Apache 2.0). Inpainting uses SDXL Inpainting 0.1 (CreativeML OpenRAIL++-M). C2PA manifests in this repo are signed with the public c2pa-python test certificate and will show as untrusted; they demonstrate the format, not a trusted signer.
